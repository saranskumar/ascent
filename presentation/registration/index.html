2

Problem statement

Meetily has strong audio context. Meetings also have a screen - and that visual context is missing today.

Meetily today: audio → transcript → summary. Missing: what’s on screen / shared video when people say “as seen here.”

Audio-only limit

What Meetily already does wellLocal recording, transcription, and summaries from speech.
What it cannot resolveDeictic speech tied to slides, dashboards, code, or diagrams - because it never sees them.

Why visuals matter live

Notes stay vagueWithout screen context, there is only a little context for summarisation.
Need appears mid-sentenceSpeaker stops to search/share a diagram - conversation breaks.
3

Proposed solution

Two layers on Meetily: first give it eyes (visual context), then give it hands (meeting assist).

Layer 1 · Visual context

See the meetingScreen/video keyframes + dHash + local OCR, fused into Meetily’s timestamped transcript.
Grounded notesResolves “as seen here” into exact facts (e.g. HTTP 504 12.4% on auth-worker). Passes the clipboard test.
Local synthesisOllama cross-references speech against on-screen content for actionable meeting notes.

Layer 2 · Meeting assist

Detect needLive Whisper stream + intent cues (“look at this”, explanatory pauses) when a visual would help.
Retrieve visualsIndexed local repo / vector cache returns 2-3 presentation-grade candidates in a side panel.
1-click assistPreview, copy, or share to screen share - no tab-switching mid-sentence.
4

30-hour MVP

Prove the core loop - not every feature.

Phase 1
Meetily → app - pull live/post transcript & context (Agent API / export hooks).
Phase 2
Context extract - topic, entities, explanatory intent → visual type (diagram / chart / image).
Phase 3
Local retrieval - small curated /assets set (architecture, algorithms, patterns) via semantic match.
Phase 4
Copilot UI - suggestion card with Preview + Share; optional screen keyframe + OCR if time allows.
5

Technology stack

Open-source, local-first components across both feature directions.

Meetily
Recording, timestamped transcript, summaries, Agent API / MCP hooks
Speech
Whisper - live transcription stream feeding the topic extractor
Keyframes
Background observer + difference hashing (dHash) to detect slide/window transitions
OCR
Tesseract OCR on changed frames only
Fusion + LLM
Chronological timeline fusion of OCR + transcript, grounded synthesis via Ollama
Retrieval
Indexed local asset repository / vector cache for diagrams and charts
6

End-to-end user journey

From live discussion and screen sharing to real-time visual assistance and complete meeting notes.

01 Speak
Explains a complex topic or incident.
Meetily transcribes and tracks conversation context live.
02 Show
Shares screen with dashboard or slides.
Vision layer captures and reads on-screen content automatically.
03 Suggest
Continues talking without searching.
Copilot proactively suggests the matching diagram in side panel.
04 Share
Clicks Share in one click.
Visual appears live on call — zero awkward pauses or tab switching.
05 Summary
Receives final meeting notes.
Spoken words and screen facts are merged into clear action items.
Live Meeting Assist · During Call Anticipates when a visual is needed and surfaces the right diagram — 1-click share keeps conversations completely uninterrupted.
Screen-Grounded Notes · After Call Connects spoken discussion with what was shown on screen — turning vague phrases like “as seen here” into clear, self-contained facts.
