# Summary
The discussion revolved around integrating screenshots with meeting transcripts to enhance the summary engine. The main challenge is to extract the existing summary engine from Meetly, adapt it to incorporate visual information, and then implement it within their own application. The team aims to create a more comprehensive summary by combining audio transcripts and visual screen captures, potentially duplicating or modifying Meetly's current summary engine for their custom application.

# Main Topics
## Current Limitations of Meetly API
The current Meetly API endpoints do not allow direct injection of summary content or visual context from photos. It's not possible to convert photos to text and inject that text directly. Additionally, integrating screenshots or screen recordings directly through Meetly is not supported. The API only allows retrieving information about meeting start and end times, and obtaining transcripts once a meeting concludes.

## Proposed Solution: Custom Python App for Screenshot Integration
The proposed solution involves developing a Python application that launches alongside Meetly. When a meeting starts, the app would prompt the user to select a window for screen grabbing. While the exact logic for screen grabbing isn't fully clear, the idea is to continuously take screenshots (e.g., every 5 seconds) throughout the meeting. Once Meetly's webhook indicates the meeting has ended, and the transcript is ready, the app would fetch the transcript via API. The challenge then becomes correlating these screenshots with the corresponding timestamps in the transcript.

## Leveraging and Modifying Meetly's Summary Engine
The team discussed how to create a summary. Initially, Meetly's builtin summary engine would generate a summary. However, the goal is to enhance this by incorporating visual data. The idea is to extract Meetly's summary engine, essentially duplicating its code, and then modify it within their own application to include the visual capabilities from the screenshots. This would allow their app to produce a more enriched summary by combining the transcript with visual context. There was a discussion about whether to build their own summary engine or modify Meetly's existing one, with the consensus leaning towards modifying Meetly's to achieve the desired outcome of integrating visual information.
