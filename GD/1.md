# Main Topics
## Introduction to Hackathon Project 'Ascent'
The meeting begins with introductions from Harinarayanan, Sreevardhan, and Meharin. They introduce their hackathon project, 'Ascent', which aims to enhance the Meetly AI product. Meetly AI is an opensource meeting AI assistant that runs locally, records audio input/output (both microphone and system audio), transcribes the meeting audio, and provides a local summary of the transcription. Users can either run their own models or use API keys from other providers.

## Visual Context Summary Feature
The team discusses adding a visual context summary feature to Meetly AI. This feature aims to summarise shared presentations, images, and project files, in addition to the existing audio summary. Initially, video summarisation was deemed unnecessary, with the focus being on screenshots and technical analysis of visual content. The current idea is to enhance the summaries by rarely providing screenshots directly but primarily using them to drive the summary text content. This feature is considered a high priority as it aligns well with the current Meetly product.

## Meeting Co-pilot Feature
Another proposed feature is a copilot for meetings, specifically designed for the person speaking. As the speaker talks, the app would listen to the topics, provide useful diagrams or visualisations from either a local image set or by instantly Googling images, and display them to the speaker. If the speaker clicks on an image, it would be displayed to all other participants. An example given is if the speaker talks about a 'drivetrain', the app would show three photos of drivetrains. This feature is intended to provide a better idea or good suggestions for the speaker to continue their conversation, searching for technical details and presenting them as key points. However, the team clarifies that the meeting copilot is not a priority, as the visual summary feature fits better with the current Meetly product
