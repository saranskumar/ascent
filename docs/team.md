## Pitch (one line)

Meetily today understands meetings from audio. We add two layers: visual context so it can see the meeting, and meeting assist so it can help in the moment.

## Core framing

| Meetily today | With Visual Copilot |
| --- | --- |
| Audio context only (listen → transcribe → summarize) | Audio + visual/video context |
| Cannot resolve “as seen here” | Screen-grounded notes |
| No live visual assist | Detect need → suggest → 1-click share |
